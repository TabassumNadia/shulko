# Version floors, not exact pins.

# Exact pins from one library generation break on a newer Python: pip
# resolves the whole file before installing anything, so a single
# incompatible pin means nothing installs at all. Floors let pip pick a
# set that works on your interpreter. The code imports defensively where
# LangChain moved things between 0.3 and 1.x.
